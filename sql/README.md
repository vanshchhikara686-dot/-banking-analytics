# SQL Server Analysis

This folder contains SQL queries developed for the Banking Analytics project using Microsoft SQL Server.

### Analysis Areas

- Customer segmentation and demographics
- Customer income analysis
- Account types and balances
- Transaction volume and value
- Transaction channel performance
- Loan portfolio analysis
- Credit-risk categorisation
- Loan default analysis
- Branch performance
- Monthly transaction trends

### SQL Skills Demonstrated

- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- JOIN operations
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- ROW_NUMBER() and DENSE_RANK()
- LAG() for time-series comparisons

**Tool:** Microsoft SQL Server Management Studio (SSMS)

# Banking Analytics – Project Documentation

This folder contains supporting documentation for the Banking Analytics project, including dataset descriptions, column definitions, data relationships and analytical references.

### Documentation Contents

| File | Description |
|---|---|
| `data_dictionary.md` | Explains dataset worksheets, columns, data types, definitions and relationships. |
| `README.md` | Provides an overview of the documentation resources. |

### Data Dictionary Coverage

- Customers – Customer profiles, demographics, income and segments.
- Accounts – Account types, balances and account status.
- Transactions – Transaction dates, amounts, channels and statuses.
- Loans – Loan amounts, outstanding balances, interest rates and loan status.
- Credit Scores – Credit scores, risk categories and payment history.
- Branches – Branch names, locations and classifications.

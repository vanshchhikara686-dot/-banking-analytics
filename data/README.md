# Banking Analytics Dataset

This folder contains the Excel dataset used for the Banking Analytics project.

### Dataset Contents

| Worksheet | Records |
|---|---:|
| Customers | 1,200 |
| Accounts | 1,464 |
| Transactions | 15,000 |
| Loans | 1,800 |
| Credit Scores | 1,200 |
| Branches | 20 |

### Purpose
The dataset supports analysis of customer behaviour, account balances, transaction patterns, loan portfolios, credit-risk categories and branch performance.

**Format:** Excel (.xlsx)

**Note:** This is synthetic portfolio data created for analytical practice.

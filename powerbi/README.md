# Banking Analytics Dashboard

This folder contains the interactive Power BI report developed for the Banking Analytics project.

### Dashboard Objectives

- Analyse customer distribution and segmentation.
- Monitor account balances and account types.
- Evaluate transaction activity and channels.
- Understand loan portfolio performance.
- Explore credit-risk categories.
- Compare banking performance across branches.

### Power BI Skills Demonstrated

- Data import and transformation
- Data modelling and relationships
- DAX measures and calculated metrics
- KPI cards
- Interactive charts and visualisations
- Business intelligence reporting

**Tool:** Microsoft Power BI Desktop

**File:** Banking_Analytics.pbix
